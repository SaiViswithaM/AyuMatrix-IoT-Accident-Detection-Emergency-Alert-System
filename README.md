\ AyuMatrix – IoT Accident Detection \& Emergency Alert System



AyuMatrix is an IoT-based accident detection and emergency alert system designed to support faster emergency response for two-wheeler riders.



The project combines accident sensing, ESP32-based processing, GPS location tracking, emergency communication, and a Flutter mobile application.



\🚀 Project Components



\- ESP32-based IoT accident detection

\- Accelerometer and gyroscope sensing

\- Heartbeat/pulse monitoring

\- GPS location tracking

\- Emergency alert communication

\- Flutter mobile application

\- Emergency confirmation and escalation workflow



\ 📱 Flutter Application



The Flutter mobile application is currently under active development as part of the AyuMatrix project.
