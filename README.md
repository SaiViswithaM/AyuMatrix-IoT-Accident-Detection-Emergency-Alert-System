# AyuMatrix – IoT Accident Detection & Emergency Alert System

**AyuMatrix** is an IoT-based accident detection and emergency alert system designed to support faster emergency response for two-wheeler riders.

The project combines accident sensing, ESP32-based processing, GPS location tracking, emergency communication, and a Flutter mobile application into a technology-driven emergency response system.

---

## 🚀 Project Overview

AyuMatrix focuses on detecting accident-related events and supporting timely emergency response through connected hardware, communication technologies, and a mobile application.

### Key Components

- ESP32-based IoT accident detection
- Accelerometer and gyroscope sensing
- Heartbeat / pulse monitoring
- GPS-based location tracking
- Emergency alert communication
- Flutter mobile application
- Emergency confirmation and escalation workflow

---

## 📱 Flutter Mobile Application

The Flutter mobile application is currently under active development as part of the AyuMatrix project.

The application is being developed to provide a mobile interface for interacting with the AyuMatrix emergency-response system and its future hardware integration.
